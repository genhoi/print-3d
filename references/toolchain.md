# Configure and run local tools

Python 3.11+ is required; Python 3.12 is tested. Install `requirements.txt` in an isolated environment. Add `requirements-cad.txt` when working with CadQuery. Blender and OpenSCAD are separate applications.

The launcher finds tools through PATH and uses its own interpreter as the default Python. To specify installations, copy `scripts/tools.example.json` to `scripts/tools.local.json` and edit it. This file is ignored by Git. An alternative file can be selected with `PRINT3D_TOOLS` or `run_3d.py --config /path/to/tools.json ...`; the explicit CLI option wins. Relative executable paths resolve from the config file's directory. A bare command name is resolved through PATH.

```sh
python scripts/run_3d.py doctor
python scripts/run_3d.py python examples/bracket.py --output-dir outputs/bracket
python scripts/run_3d.py inspect outputs/bracket/bracket.stl --expect-extents 60 36 32 --expected-components 1 --output outputs/bracket/mesh.json
python scripts/run_3d.py render --input outputs/bracket/bracket.stl --output outputs/bracket/preview/model.png --blend-output outputs/bracket/preview/scene.blend
python scripts/run_3d.py render --input outputs/bracket/bracket.stl --output outputs/bracket/preview/bottom.png --view bottom
python scripts/run_3d.py blender path/to/build.py --output path/to/output
python scripts/run_3d.py scad -o outputs/part.stl source/part.scad
```

Run these with the dedicated environment's Python or after activating that environment. Use quoted absolute paths when a project path contains spaces. In PowerShell, an executable path is invoked with `&`.

`doctor` checks Python packages in the configured interpreter; it reports optional applications separately. A successful core check does not imply that Blender or OpenSCAD is installed. A successful executable version check does not test all export operations.

Blender script runs use `--background --factory-startup --python-exit-code 1 --python SCRIPT -- ARGS`. The preview helper accepts an STL whose coordinates are in mm, keeps the source mesh unchanged and creates a separate scene. It refuses existing outputs unless `--overwrite` is given. Never use an editable source scene as a preview destination, even when overwriting is intentional.

The OpenSCAD wrapper also protects explicit `-o` destinations and accepts wrapper aliases `--output`/`--output=...`. `--overwrite` permits replacing generated exports; it does not permit replacing an input file. This guard does not enumerate animation frames or auxiliary files generated by arbitrary OpenSCAD options; direct those to a fresh output directory. `python` and `blender` actions execute the supplied script, whose own output handling remains responsible for preservation.

The inspector also accepts OBJ, GLB/glTF and generic 3MF. GLB/glTF meters and declared 3MF units are converted to mm; STL/OBJ are assumed mm unless `--units` overrides that assumption. Standard scene transforms and instances are applied. Visual UV/normal splits are welded by position for topology checks without altering the file. This is not an arbitrary mesh repair command. glTF surface primitives are limited to triangles and triangle strips; other primitive modes and `EXT_mesh_gpu_instancing` are rejected instead of silently dropping geometry. This is not a complete glTF conformance validator. 3MF import disables the loader's name-based postprocessing so similarly named assembly parts are not replaced.

`--expected-components` counts material bodies, not every connected surface shell. A closed cavity has an oppositely oriented inner shell. Shell nesting, orientation, contact/overlap checks and numerical tolerances are reported; ambiguous geometry is rejected instead of silently repaired. Nested material islands count as additional bodies.

The renderer auto-fits the camera, so an image alone cannot prove physical size. Read the dimensions and compare them with the intended object. A generic 3MF report does not validate slicer-specific modifiers or profiles.
